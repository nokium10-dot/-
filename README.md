# MatrixWall + Пип

Android-проект с двумя отдельными приложениями:

- **MatrixWall Pro** — существующие живые обои.
- **Пип — виртуальный питомец** — Android-оболочка официального симулятора Pip-KeyPet.

## Сборка Пипа

GitHub Actions автоматически забирает исходники из [NovikovVisuals/Pip-KeyPet](https://github.com/NovikovVisuals/Pip-KeyPet), собирает оригинальный WebAssembly-симулятор (LVGL UI, эмоции, игры и голосовые звуки), упаковывает его вместе с Three.js в Android assets и создаёт APK.

В приложении доступны:
- оригинальный симулятор и его анимации;
- сенсорное управление и мобильная компоновка симулятора;
- русскоязычный интерфейс оригинального симулятора;
- голосовые команды на русском;
- запрос системной роли помощника Android (на версиях, где роль доступна).

Для запуска сборки откройте **Actions → Build MatrixWall and Pip APKs → Run workflow**. APK Пипа будет в артефакте `MatrixWall-and-Pip-APKs` и в последнем релизе как `Pip-KeyPet.apk`.

## Примечания

Часть функций оригинала моделирует физические датчики и Bluetooth-связь брелока; на телефоне они остаются виртуальными. Функции, требующие настоящего брелока Waveshare, не могут управлять аппаратурой телефона напрямую.

Лицензия и авторство исходного проекта Pip-KeyPet сохраняются за его авторами; исходный репозиторий используется как отдельный источник сборки.
