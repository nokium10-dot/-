# MatrixWall + Пип

Android-проект с двумя отдельными приложениями:

- **MatrixWall Pro** — существующие живые обои.
- **Пип — виртуальный питомец** — первая Android-версия симулятора Pip-KeyPet.
- **Пип Glass** — отдельная Liquid Glass-версия с уникальным package ID `com.pipkeypet.glass`; устанавливается рядом с первой версией.

## Сборка Пипа

GitHub Actions автоматически забирает исходники из [NovikovVisuals/Pip-KeyPet](https://github.com/NovikovVisuals/Pip-KeyPet), собирает оригинальный WebAssembly-симулятор (LVGL UI, эмоции, игры и голосовые звуки), упаковывает его вместе с Three.js в Android assets и создаёт APK.

В обеих версиях доступны:
- оригинальный симулятор и его анимации;
- сенсорное управление и мобильная компоновка симулятора;
- русскоязычный интерфейс оригинального симулятора;
- голосовые команды на русском;
- запрос системной роли помощника Android (на версиях, где роль доступна).

Для запуска сборки откройте **Actions → Build MatrixWall and Pip APKs → Run workflow**. Новая версия собирается отдельным Gradle-модулем `pipglass`. APK будут в артефакте `MatrixWall-and-Pip-APKs`. Новая версия публикуется в последнем релизе как `Pip-Glass.apk`, первая версия остаётся `Pip-KeyPet.apk`.

## Примечания

Часть функций оригинала моделирует физические датчики и Bluetooth-связь брелока; на телефоне они остаются виртуальными. Пип Glass заявляет себя системным голосовым помощником Android через VoiceInteractionService; доступность выбора зависит от производителя и версии Android. Голосовой ввод использует системный распознаватель речи и требует его наличия. Функции, требующие настоящего брелока Waveshare, не могут управлять аппаратурой телефона напрямую.

Лицензия и авторство исходного проекта Pip-KeyPet сохраняются за его авторами; исходный репозиторий используется как отдельный источник сборки.
