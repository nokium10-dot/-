# Пип · русская версия (отдельное приложение)

Android-приложение **«Пип 2»** (`com.pipru.v2`) — оригинальный симулятор
[Pip-KeyPet](https://github.com/NovikovVisuals/Pip-KeyPet) (LVGL → WebAssembly + 3D-брелок) с русским
мобильным интерфейсом и голосовым помощником.

Это **отдельная** версия (рядом с `pip-ru/`, пакет `com.pipru.assistant`): свой пакет, имя, workflow и релиз. С PipAltVer (`com.pipaltver.mobile`) и
оригинальным Pip-KeyPet (`com.pip.keypet`) не конфликтует — можно держать на телефоне все сразу.

## Как получить APK

1. На GitHub: **Actions → Build Pip RU 2 (separate app) → Run workflow** (или любой push в `pip-ru2/`).
2. APK появится в релизе **pipru2-latest** (`Pip-RU2.apk`) и в артефакте `Pip-RU2-APK`.
3. Скачайте на телефон и установите (разрешите установку из неизвестных источников).

Подпись: если в Secrets заданы `ANDROID_KEYSTORE_BASE64`, `ANDROID_KEYSTORE_PASSWORD`, `ANDROID_KEY_ALIAS`,
`ANDROID_KEY_PASSWORD` — используется ваш ключ. Иначе ключ создаётся при первой сборке и хранится в кэше Actions,
поэтому новые версии ставятся поверх старых. Если кэш Actions очистится (7 дней без сборок), ключ изменится и
придётся один раз удалить приложение перед установкой.

## Голосовой помощник

Приложение объявляет `VoiceInteractionService`, поэтому Пип появляется в
**Настройки → Приложения → Приложения по умолчанию → Цифровой помощник**. Выбрать можно и в самом приложении:
**⚙ Настройки → Голосовой помощник**. После выбора удержание кнопки «Домой»/питания или жест из угла экрана
открывает Пипа, и он сразу слушает. Команды на русском: «покорми», «поиграй», «погладь», «усни», «как дела»,
«открой меню», «который час» и др. (список — в настройках приложения). Распознавание речи делает сервис Google
на телефоне (нужен интернет), ответы Пип озвучивает синтезатором речи Android.

## Интерфейс

- Брелок на весь экран; щипок двумя пальцами — масштаб, потянуть за корпус — наклон.
- Быстрые действия внизу: покормить, поиграть, погладить, меню.
- Меню с вкладками (плавные анимации, смахивание вниз): **Забота**, **Эмоции**, **Звук**, **Управление**,
  **Связь**, **Настройки** — здесь все функции оригинального симулятора (тамагочи, ~90 эмоций, голоса, виртуальный
  гироскоп и датчики, кнопки корпуса, эмуляция iPhone и компьютера, темы, цвет корпуса).

## Как устроено

`.github/workflows/build-pip-ru2.yml` забирает исходники Pip-KeyPet (закреплена проверенная версия, можно
указать другую при ручном запуске), собирает симулятор в WebAssembly и кладёт в `assets`.
`pip-ru2/tools/build_web.py` патчит оригинальный `index.html`, добавляя интерфейс из `pip-ru2/web/`
(`mobile.css`, `mobile.html`, `mobile.js`). Приложение работает офлайн, разрешение только на микрофон.

Лицензия оригинала (MIT) и авторство принадлежат авторам Pip-KeyPet.
