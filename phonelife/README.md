# PHONE LIFE 3D

Отдельное Android-приложение в альбомной ориентации. Игровой прототип: мастерская, рублёвая экономика, закупка деталей и б/у телефонов, сборка, продажа, обмен и поездка на электросамокате. Сцена построена на OpenGL ES 2.0 с процедурными 3D-моделями и простыми анимациями.

Сборка: `gradle :phonelife:assembleDebug`.
Package: `com.phonelife.sim`.
